# Creative Technology Projects

A collection of creative technology, human–AI interaction and computational media projects developed during my MSc in Applied Machine Learning for Creatives at University of the Arts London.

My practice explores how machine learning, computer vision, physical interaction and generative systems can be used as creative materials. These projects combine technical experimentation with visual communication and interaction design.

## Projects

### Right to Pause

An interactive installation exploring bodily autonomy, refusal and the right to interrupt AI-mediated systems.

The project combines capacitive touch sensing with a browser-based interface, allowing physical actions to pause, interrupt or alter the behaviour of a digital system.

**Technologies:** Arduino, MPR121, JavaScript, HTML/CSS, physical computing and web interaction.

[View project files](./RightFinal-main)

---

### Performing Data

An interactive audiovisual experiment that transforms hand movements into live sound and visual behaviours.

Real-time hand-tracking data is transmitted through OSC and interpreted as expressive input, connecting bodily gestures with computational performance.

**Technologies:** Python, MediaPipe Hands, OSC, Dorothy, interactive sound and generative visuals.

[View project files](./Performing-data-main%202)

---

### Fridge Inventory AI

A group project investigating how computer vision could support domestic food management.

The prototype uses object detection to recognise and track food items inside a fridge, connecting detection results to a responsive interface through a lightweight backend.

**Technologies:** Python, YOLOv8, OpenCV, FastAPI, WebSocket and interface prototyping.

[View project files](./MML-Fridge-main)

---

### DebatePartner

A conversational AI prototype designed to support debate, reflection and exploratory dialogue.

Users can interact with either an optimistic or sceptical conversational personality. The system combines sentiment analysis, semantic embeddings, topic tracking and conversational memory to generate context-sensitive responses.

**Technologies:** Python, VADER sentiment analysis, Sentence Transformers, semantic embeddings and natural language processing.

[View project files](./DebatePartner)

---

### Computational Media Experiments

A collection of creative coding studies exploring sound, motion, machine perception, noise and generative visual systems.

The experiments include audio mixing, FFT-based visualisation, beat-responsive graphics, OpenCV motion detection, temporal image blending, particle systems and low-resolution visual effects.

**Technologies:** Python, Dorothy, OpenCV, NumPy, Librosa and computational audiovisual design.

[View project files](./Computational-Media-Experiments)
