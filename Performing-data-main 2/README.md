
# Main Files

- `performingFinal.py` - final performance program.
- `diffusion_utils.py` - Stable Diffusion img2img helper.
- `record gestures.py` - gesture recording tool used to create the training data.
- `gesture_data.pkl` - recorded gesture dataset for the KNN classifier.
- `hand_landmarker.task` - MediaPipe hand tracking model.
- `sounds/` - sound files used for background and state-based audio.
- `Process/` - earlier code iterations and process documentation.
- `Reflection.md` - written reflection, references, audience feedback, and project evaluation.
- `System Diagram.png` - signal flow / system diagram.
